# Xray for Windows

Download an official Windows Xray-core release from <https://github.com/XTLS/Xray-core/releases> and extract the complete archive into this directory before running `windows/install-windows.ps1`.

Do not commit or redistribute an Xray binary from this directory as if it were WProxy source. Xray has its own license and release process. The WProxy source archive intentionally contains only this note.
